# 贝叶斯应用案例作业

根据[作业题目](贝叶斯应用案例作业.docx)第二部分，使用线上学习平台的 A/B 测试数据，判断新版 B 的「进入课程」按钮点击率是否更高。当前已完成任务 1。

| 目录 | 对应要求 | 进度 |
| --- | --- | --- |
| [任务1](任务1/) | 建立两个版本点击率的贝叶斯模型 | 已完成 |
| [任务2](任务2/) | 分别计算 A 和 B 的后验分布 | 待完成 |
| [任务3](任务3/) | 比较点击率，计算 B 优于 A 的后验概率和各组后验均值 | 待完成 |
| [任务4](任务4/) | 绘制后验分布、重叠部分及 B 优于 A 的概率区域或抽样结果 | 待完成 |
| [任务5](任务5/) | 给出版本采用建议，并估算识别较小提升所需的样本量 | 待完成 |

## 运行任务 1

在项目根目录运行以下命令。任务 1 使用指定的conda环境，Python 版本为 3.13。

```bash
python -m pip install -r requirements.txt
python -m 任务1.model
```

脚本会输出两组的访问与点击人数、观测点击率、先验和似然设定。完整推导见[任务 1 建模说明](任务1/README.md)。
